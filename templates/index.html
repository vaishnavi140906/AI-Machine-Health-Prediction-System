💡 About The System

AI-powered predictive maintenance for industrial machines

🏭 AI-Based Predictive Machine Maintenance

This project is designed to help manufacturing industries monitor machine health and identify possible failures before they occur.

The system receives machine sensor parameters such as air temperature, process temperature, rotational speed, torque and tool wear. These values are processed using a trained deep learning model to estimate the probability of machine failure.

The predicted probability is converted into a machine health score and risk level, helping maintenance teams make faster and more informed decisions.
